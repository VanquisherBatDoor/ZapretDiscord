> ### Реакция антивирусов
> WinDivert иногда обнаруживается антивирусом.  
> Это средство перехвата и фильтрации трафика, которое требуется для работы zapret.
> Его могут применять и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса или отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений лучше добавить нужное исключение, но если вы не уверены в своих действиях, рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите Secure DNS.
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите настройку "Транзит запросов". Если её отключить, Secure DNS на компьютере может работать некорректно.

2. Перейдите на [страницу последнего релиза](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases/latest) и скачайте архив zip или rar.

3. Откройте свойства архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите в **`service.bat`** пункт `Install Service`, а затем нужную стратегию.

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) - управление автозапуском и дополнительными возможностями:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - убрать стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  После изменения параметра стратегию необходимо перезапустить.  
  В скобках показывается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - выбрать режим обработки сервисов из `ipset-all.txt`.  
  Опция полезна при диагностике ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках отображается текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сопоставляется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - получить из репозитория свежий `ipset-all.txt`
  - **`Update Hosts File`** - обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает работоспособность.
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - протестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Частые вопросы и неполадки

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен открыться winws.exe, отвечающий за обход. Его можно заметить на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте текстовым редактором от имени администратора файл `hosts` в появившейся папке.
  - Вставьте скопированные строки в конец `hosts` или замените ими ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение. При отсутствии результата убедитесь, что изменения действительно сохранились.

#### Результат не гарантирован. Если способ не сработал, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/VanquisherBatDoor/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> После обнаружения конкретная стратегия иногда перестаёт работать, даже если до этого долго помогала.
> В репозитории собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`.

- Убедитесь, что нужный адрес есть в списках доменов или IP.

- Переберите другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Откройте `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой мыши по архиву и откройте свойства. Если внизу есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general`, проверяя доступность ресурсов. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующий.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё находится среди служб

1. В командной строке Windows, открытой через Win+R и `cmd`, определите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежний вариант перестал помогать, протестируйте остальные стратегии.
- См. также [#251](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Для начала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord.
- Снова проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте её.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/VanquisherBatDoor/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не работают игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Попробуйте следующий общий порядок:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если результата нет, дополнительно активируйте режим `ipset any`.

Учтите: `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues).

## 🗒️Как добавить адреса других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети уже есть в `ipset-all.txt`, но определённый домен из неё фильтровать не нужно.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые требуется исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
