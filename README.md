>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и помещается в карантин. Название обнаружения обязательно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса или отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При грамотном понимании настроек лучше добавить исключение; если вы не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Активируйте безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS в настройках самой системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); этот способ рекомендуется пользователям Windows 11.
   * На роутерах Keenetic включите параметр "Транзит запросов". При отключении этой опции Secure DNS на компьютере может работать неправильно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и включите флажок "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот шаг не требуется.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий скрипт.
   * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
   * Для установки стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> нужную стратегию.

## ℹ️ Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** помещает выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  Текущее состояние указывается в скобках: включено или выключено.
  - **`IPSet Filter`** включает или выключает обход сервисов из `ipset-all.txt`.  
  Эта настройка полезна при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках отображается состояние:
    - `none` — IP-адреса не проходят проверку;
    - `loaded` — адрес проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>.
  - **`Check for Updates`** вручную проверяет наличие новой версии.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце процедуры можно очистить кэш <img src='https://cdn-icons-png.flaticon.com/128/5968/5968756.png' height=11 /> `Discord`, что иногда возвращает работоспособность.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe. Если этого не произошло, обратитесь к [#522](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/522).

### Подходящей стратегии нет

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

  `netsh winsock reset`

  `netsh int ip reset all`

  `netsh winhttp reset proxy`

  `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается веб-версия Telegram

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в появившемся каталоге текстовым редактором, запущенным от имени администратора;
- вставьте скопированное в конец `hosts` или замените ранее добавленный аналогичный блок;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/VanquisherBatDoor/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем переставать работать.**
> Обнаружение конкретной стратегии способно произойти спустя некоторое время, даже если сначала она работала.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках.
- Проверьте, есть ли адрес ресурса в списках доменов или IP.
- Испытайте другие варианты, например **`ALT`** или **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните ошибки и в конце подтвердите действие клавишей Y.
- Удалите старый каталог zapret.
- Скачайте свежую версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases).
- Нажмите правой кнопкой по архиву, откройте свойства и, если внизу справа доступен флажок разблокировки, включите его, затем нажмите применить и OK.
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу через значок замка в панели задач и попробуйте другую стратегию.
- Найдя рабочий вариант, установите его в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

Инструкция доступна в разделе https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте название службы в командной строке Windows, открытой через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src='https://cdn-icons-png.flaticon.com/128/1384/1384060.png' height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/251).

### Не работает <img src='https://cdn-icons-png.flaticon.com/128/5968/5968756.png' height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8F-использование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, используйте её.
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/252).

### Не работает <img src='https://cdn-icons-png.flaticon.com/128/5968/5968804.png' height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/VanquisherBatDoor/tg-ws-proxy).
- Либо воспользуйтесь бесплатным MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальный порядок действий:

- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учитывайте, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Создайте обращение [здесь](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — исключаемые домены, например домен из сети, чей IP уже указан в `ipset-all.txt`, но фильтровать его не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
